# Optimized-MT64

An optimized Mersenne Twister 64-bit implementation featuring algorithmic improvements and configurable n-bit random number generation.

## Overview

This project contains a software implementation based on the 64-bit Mersenne Twister pseudorandom number generator (MT64).

The implementation incorporates internal algorithmic optimizations and introduces configurable n-bit random number generation through dedicated internal generation blocks.

This project originated from prior research and development work and is maintained as a standalone software project.

## Features

- **MT64-based pseudorandom number generation:** Based on the 64-bit Mersenne Twister algorithm.
- **Algorithmic optimizations:** Improvements to selected internal algorithmic processes.
- **Configurable n-bit generation:** Dedicated internal generation blocks supporting configurable output bit widths.
- **Standalone implementation:** Designed for independent development, evaluation, and reproducibility.
